# AI Response Comparison Project

A comprehensive evaluation comparing two AI responses to the same prompt, demonstrating how different models approach similar tasks.

## Project Overview

This project contains a detailed analysis of AI responses from different models to the same prompt. The evaluation follows a structured methodology to assess response quality based on:

- **Following Instructions**: Does the response do what the prompt asks?
- **Accuracy**: Are claims factually correct?
- **Clarity and Usefulness**: Does it communicate clearly for the intended audience?

## Contents

- `evaluation.md` - Detailed comparison and analysis
- `responses.md` - Full text of both responses
- `verdict.md` - Final judgment with evidence
- `screenshots/` - Visual documentation

## How to Use This Project

1. Read `evaluation.md` for the full analysis
2. Review `responses.md` to see both complete responses
3. Check `verdict.md` for the final judgment and reasoning

## Methodology

The comparison uses a structured approach to ensure fair assessment:
1. Identify what the prompt requires
2. Establish 2-3 evaluation criteria
3. Apply same standards to both responses
4. Base judgment on responses themselves, not model names or length
5. Support verdict with specific evidence
